# 🚌 Last Stop Wiki & Interactive Database

High-performance, Next.js 14 SSG community database and interactive toolkit for **Last Stop** on Roblox (developed by The Hidden Route).

## 🚀 Features
- **Bus Fuel & Range Simulator** (`/calculator`): Real-time physics calculator computing coal and canister burn rates towards 95,000 meters.
- **Active Tickets Codes Hub** (`/codes`): 1-click clipboard copy with verified active codes.
- **Survivor Classes Tier List** (`/class-tier-list`): Tier rankings and interactive dual-class comparison panel.
- **Weapons & Armory** (`/weapons-guide`): DPS, fire rates, and optimal range for all firearms and melee.
- **Bus Upgrades Tech Tree** (`/bus-upgrades`): Complete upgrade path for engines, spiked cowcatchers, and mounted turrets.
- **Infected Bestiary** (`/zombies-bestiary`): Threat index and boss counter tactics.
- **Beginner Survival Guide** (`/beginner-guide`): Day 1 roadmap to 95,000m.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router, Static HTML Export)
- **Styling**: Tailwind CSS, Frosted Glassmorphism, Diesel Apocalypse Palette
- **Icons**: Lucide React
- **SEO**: Dynamic Sitemap XML, JSON-LD Schema (WebSite, FAQPage, WebApplication, ItemList)

## 📦 Build Instructions
```bash
npm run build
```
Generates 100% static production bundle in `./out`.
